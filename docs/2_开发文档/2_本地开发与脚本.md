# 本地开发与脚本

本文说明如何在本地启动 NewHuman MVP 服务，以及 `scripts/` 目录下各脚本的用途。

---

## 1. 环境要求

| 项 | 要求 |
|----|------|
| Conda | Miniconda / Anaconda / Miniforge（**推荐**） |
| Python | 3.12（由 `environment.yml` 固定） |
| 操作系统 | Windows / Linux / macOS |
| LLM | OpenAI 兼容 API，**须支持 Tool Calling** |

### 1.1 Windows：请使用 PowerShell，不要用 CMD

本仓库在 Windows 上的启动、测试脚本均为 **`.ps1`（PowerShell）**，请在 **PowerShell** 或 **Windows Terminal（PowerShell 配置文件）** 中运行。

| 终端 | 是否推荐 | 说明 |
|------|----------|------|
| **PowerShell** | ✅ 推荐 | 直接运行 `.\scripts\*.ps1` |
| **Windows Terminal（PowerShell）** | ✅ 推荐 | 同上 |
| **CMD（命令提示符）** | ❌ 不推荐 | 无法直接执行 `.ps1`；环境变量、路径、编码行为与文档不一致，易报错 |
| **Git Bash** | ⚠️ 部分可用 | 请用 `*.sh` 脚本；`.ps1` 需另行调用 PowerShell |

**正确示例（PowerShell）：**

```powershell
cd E:\personal_project\NewHuman
.\scripts\setup_conda.ps1
.\scripts\run_agent.ps1
```

**若当前只有 CMD 窗口**，可显式调用 PowerShell（仍建议在 PowerShell 中日常开发）：

```cmd
cd /d E:\personal_project\NewHuman
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup_conda.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_agent.ps1
```

**首次运行若提示「无法加载，因为在此系统上禁止运行脚本」**，在 **以管理员打开的 PowerShell** 中执行一次：

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

或在单次调用时加 `-ExecutionPolicy Bypass`（见上方 CMD 示例）。

> **说明：** Agent 工具 `exec_powershell` 在 workspace 内执行的是 PowerShell 命令；与「用 PowerShell 启动项目脚本」是同一运行时，请勿在 CMD 中手动 `python -m func.graph.run` 后困惑于路径/编码问题——优先走 `.\scripts\run_agent.ps1`。

## 2. 首次配置

### 2.1 创建 Conda 环境

```powershell
cd E:\personal_project\NewHuman
.\scripts\setup_conda.ps1
```

Linux / macOS：

```bash
chmod +x scripts/setup_conda.sh
./scripts/setup_conda.sh
```

环境名默认 **`newhuman`**。自定义名称：

```powershell
$env:NEWHUMAN_CONDA_ENV = "my-env"
.\scripts\setup_conda.ps1
```

**更新依赖**（`requirements.txt` 变更后）：

```powershell
.\scripts\setup_conda.ps1   # 自动 conda env update
# 或完全重建
.\scripts\setup_conda.ps1 -Recreate
```

**手动激活**（当前终端会话）：

```powershell
conda activate newhuman
# 或
.\scripts\activate.ps1
```

> 所有 `scripts/*.ps1` 启动脚本会通过 `conda run -n newhuman` 自动使用正确 Python，**不激活也能运行**。

### 2.2 配置环境变量

```powershell
copy code\app\.env.demo code\app\.env
```

编辑 `code/app/.env`，至少配置：

```ini
LLM_MODEL_NAME=your-model
LLM_MODEL_BASE_URL=https://your-api/v1
LLM_MODEL_API_KEY=sk-...
LLM_MODEL_API_TYPE=openai

SERVICE_HOST=0.0.0.0
SERVICE_PORT=8000
```

Embedding / 向量库可在 M3 知识库阶段再配。

### 2.3 初始化 Workspace

```powershell
.\scripts\setup_workspace.ps1
```

会在仓库根创建 `workspace/default/`，包含 `SOUL.md`、`AGENTS.md` 等 Bootstrap 模板（见设计文档 §6.3）。

## 3. 启动服务

### Windows（推荐）

在 **PowerShell** 中执行（不要用 CMD，见 [§1.1](#11-windows请使用-powershell不要用-cmd)）：

```powershell
.\scripts\start_server.ps1
```

可选参数：

| 参数 | 说明 |
|------|------|
| `-Port 8080` | 覆盖监听端口 |
| `-Reload` | 开启 uvicorn 热重载（Windows 下可能导致浏览器超时，慎用） |

停止占用端口的本地服务（默认读取 `.env` 中的 `SERVICE_PORT`，否则 8000）：

```powershell
.\scripts\stop_server.ps1
.\scripts\stop_server.ps1 -Port 8080
```

### Linux / macOS

```bash
chmod +x scripts/start_server.sh
./scripts/start_server.sh
# 或指定端口: ./scripts/start_server.sh 8080
```

### 验证

| 地址 | 说明 |
|------|------|
| http://127.0.0.1:8000/ | 首页（链接到 Chat / Docs） |
| http://127.0.0.1:8000/chat | **浏览器聊天界面**（流式 SSE） |
| http://127.0.0.1:8000/docs | Swagger UI |
| http://127.0.0.1:8000/health | 健康检查 JSON |

**说明：** 本地默认 `NACOS_ENABLED=false`、**不使用 `--reload`**（Windows 下 reload 可能导致浏览器无法访问）。需热重载时：`.\scripts\start_server.ps1 -Reload`。

## 4. 脚本一览

| 脚本 | 平台 | 作用 |
|------|------|------|
| `scripts/setup_conda.ps1` | Windows | 创建/更新 conda 环境 `newhuman` |
| `scripts/setup_conda.sh` | Unix | 同上 |
| `scripts/activate.ps1` | Windows | 当前会话激活 conda 环境 |
| `scripts/start_server.ps1` | Windows | 检查 `.env`、启动 uvicorn（conda） |
| `scripts/stop_server.ps1` | Windows | 按端口号停止监听中的服务进程 |
| `scripts/start_server.sh` | Unix | 同上 |
| `scripts/run_agent.ps1` | Windows | **终端交互** Agent（conda） |
| `scripts/setup_workspace.ps1` | Windows | 创建 `workspace/default` 模板 |
| `scripts/setup_workspace.sh` | Unix | 调用 PowerShell 或 bash 兜底 |
| `scripts/run_tests.ps1` | Windows | 运行 pytest（conda） |
| `scripts/run_tests.sh` | Unix | 同上 |
| `scripts/check_milestone.py` | 全平台 | 里程碑门禁 |

环境变量：

| 变量 | 默认 | 说明 |
|------|------|------|
| `TEST_BASE_URL` | `http://127.0.0.1:8000` | 集成测试 API 地址 |
| `TEST_USER` | `mvp-test-user` | 测试请求 user 字段 |
| `NEWHUMAN_CONDA_ENV` | `newhuman` | conda 环境名称 |
| `WORKSPACE_ROOT` | `{repo}/workspace/default` | Agent 工作区 |

## 5. 本地调试 Agent（不经过 HTTP）

**推荐 — 终端直接对话（read_file / exec_powershell 等）：**

```powershell
.\scripts\run_agent.ps1
```

或手动（需先 `conda activate newhuman`）：

```powershell
conda activate newhuman
cd code\app
$env:PYTHONPATH = (Get-Location)
python -m func.graph.run
```

终端命令：`/new` 新会话、`/history` 历史、`/exit` 退出。

**通过 HTTP API 对话（Postman / 脚本 / 前端）：**

```powershell
# 终端 1
.\scripts\start_server.ps1

# 终端 2 — 示例
curl -X POST http://127.0.0.1:8000/v1/chat-messages `
  -H "Content-Type: application/json" `
  -d '{"query":"用 PowerShell 列出 workspace 文件","response_mode":"blocking","user":"me","conversation_id":""}'
```

图结构可视化：

```powershell
cd code\app
python -m func.graph.show_graph
```

## 7. 常见问题

**Q: 在 CMD 里运行 `.\scripts\run_agent.ps1` 报错或无反应**  
A: Windows 脚本为 PowerShell（`.ps1`），请在 **PowerShell** 中运行，或使用：  
`powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run_agent.ps1`。详见 [§1.1](#11-windows请使用-powershell不要用-cmd)。

**Q: 启动报缺少模块**  
A: 运行 `.\scripts\setup_conda.ps1` 创建环境；通过 `start_server.ps1` / `run_agent.ps1` 启动（自动 `conda run` + `PYTHONPATH`）。

**Q: 对话 500 / Agent 无响应**  
A: 检查 `.env` 中 LLM 配置；模型须支持 function calling。

**Q: read_file 找不到 SOUL.md**  
A: 运行 `setup_workspace.ps1`；路径相对于 `workspace/default/`。

---

## 8. Conda 常见问题

**Q: 脚本报「conda 环境不存在」**  
A: 运行 `.\scripts\setup_conda.ps1`。

**Q: 想用系统 Python 而不是 conda**  
A: 不推荐。若必须，可手动 `pip install -r code/requirements.txt` 并直接 `python -m func.graph.run`（需自行设置 `PYTHONPATH=code/app`）。

**Q: 依赖更新后如何同步**  
A: 修改 `code/requirements.txt` 或 `environment.yml` 后执行 `.\scripts\setup_conda.ps1`。
