## 1. Git 分支管理

### 1.1 分支命名

| 分支类型 | 命名格式 | 示例 |
|----------|----------|------|
| 主分支 | main | 主分支 |
| 开发分支 | develop | 开发分支 |
| 功能分支 | feature/{ticket-id}-{brief} | feature/ORD-123-order-create |
| 发布分支 | release/{version} | release/v1.0.0 |
| 热修复分支 | hotfix/{ticket-id}-{brief} | hotfix/ORD-456-fix-bug |

### 1.2 Commit 规范

```
<type>(<scope>): <subject>

<body>

<footer>
```

**type 类型：**

| 类型 | 说明 |
|------|------|
| feat | 新功能 |
| fix | Bug 修复 |
| docs | 文档更新 |
| style | 代码格式 |
| refactor | 重构 |
| perf | 性能优化 |
| test | 测试相关 |
| chore | 构建/工具 |

**示例：**
```
feat(order): 添加订单超时自动取消功能

- 添加订单超时检查定时任务
- 支持配置超时时间
- 取消后自动退款

Closes #123
```

## 3. 接口规范

### 3.1 RESTful 规范

| 操作 | HTTP 方法 | URL 模式 |
|------|----------|----------|
| 查询单个 | GET | /api/v1/users/{id} |
| 查询列表 | GET | /api/v1/users |
| 创建 | POST | /api/v1/users |
| 更新 | PUT | /api/v1/users/{id} |
| 部分更新 | PATCH | /api/v1/users/{id} |
| 删除 | DELETE | /api/v1/users/{id} |

### 3.2 版本控制

```
/api/v1/users
/api/v2/users
```

### 3.3 响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": {},
  "traceId": "abc123",
  "timestamp": 1714281600000
}
```

## 4. 数据库规范

### 4.1 表设计规范

1. **必须有主键**：使用 bigint 自增主键
2. **必须有审计字段**：create_time, update_time, deleted
3. **必须添加索引**：根据查询场景添加合适索引
4. **必须添加注释**：表注释、字段注释
5. **禁止全表扫描**：必须走索引

### 4.2 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 表名 | 小写下划线 | order_info |
| 字段名 | 小写下划线 | order_id |
| 索引名 | idx_字段 | idx_user_id |
| 主键 | id 或 表名_id | order_id |
| 外键 | fk_关联表 | fk_user_id |

## 5. 日志规范

### 5.1 日志级别使用

| 级别 | 场景 |
|------|------|
| ERROR | 异常情况，需要关注 |
| WARN | 警告情况，可容忍 |
| INFO | 重要业务节点 |
| DEBUG | 开发调试信息 |

### 5.2 日志格式

```json
{
  "time": "2026-04-28 10:00:00.000",
  "level": "INFO",
  "traceId": "abc123",
  "userId": "10001",
  "service": "order-service",
  "method": "createOrder",
  "message": "Order created successfully",
  "duration": 150
}
```

### 5.3 禁止事项

- ❌ 禁止打印敏感信息（密码、Token）
- ❌ 禁止打印大对象
- ❌ 生产环境禁止 DEBUG

## 6. 配置规范

### 6.1 环境配置

| 环境 | 说明 | 配置管理 |
|------|------|----------|
| dev | 开发环境 | 本地覆盖 |
| test | 测试环境 | 配置中心 |
| pre | 预发环境 | 配置中心 |
| prod | 生产环境 | 配置中心 + 加密 |

### 6.2 配置原则

1. **敏感信息加密**：密码、密钥必须加密存储
2. **配置外部化**：禁止硬编码配置
3. **环境隔离**：不同环境配置隔离
4. **版本管理**：配置变更记录审计

---

## 7. 安全规范

### 7.1 认证授权

- ✅ 所有接口必须鉴权
- ✅ 使用 JWT Token
- ✅ Token 设置有效期
- ✅ 敏感操作二次验证

### 7.2 数据安全

- ✅ 密码加密存储
- ✅ SQL 参数化查询
- ✅ 输入输出数据校验
- ✅ 敏感数据脱敏
