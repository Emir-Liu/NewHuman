# 验收测试与里程碑

本文将 [MVP 需求文档 §7、§8](../0_需求文档/MVP需求文档_v1.0.md) 中的 **TC 用例** 与 **M1~M5 里程碑** 映射到仓库内的自动化测试与门禁脚本。

---

## 1. 测试架构

```
tests/
├── conftest.py              # fixtures、API helpers、LLM/服务 skip 条件
├── test_smoke.py            # smoke：目录、health（无需 LLM）
├── test_milestone_m1.py     # M1：TC-01, TC-02
├── test_milestone_m2.py     # M2：TC-05
├── test_milestone_m3.py     # M3：TC-03, TC-08~10
├── test_milestone_m4.py     # M4：TC-06, TC-07
└── test_milestone_m5.py     # M5：TC-04

pytest.ini                   # markers: smoke, milestone_m1 ~ m5
scripts/check_milestone.py   # 里程碑门禁
```

---

## 2. 运行测试

**前置：** 服务已启动（`.\scripts\start_server.ps1`），且 `code/app/.env` 已配置 LLM。

```powershell
# 仅 smoke（无需 LLM，可服务未启动时部分 skip）
.\scripts\run_tests.ps1 -SmokeOnly

# 指定里程碑
.\scripts\run_tests.ps1 -Milestone M1

# 全部
.\scripts\run_tests.ps1

# 里程碑进度
python scripts\check_milestone.py
```

直接使用 pytest：

```powershell
cd E:\personal_project\NewHuman
$env:TEST_BASE_URL = "http://127.0.0.1:8000"
python -m pytest tests/ -m "milestone_m1 or smoke" -v
```

## 4. 里程碑门禁

`scripts/check_milestone.py` 检查两类条件：

1. **代码落点文件**是否存在（对照设计 §6.4）
2. **pytest marker** 是否通过（可选，运行时执行）

| 里程碑 | 交付物 | 关键文件 | 验收 TC |
|--------|--------|----------|---------|
| M1 | ReAct + read_file + 流式 | `nodes/llm_call.py`, `tool_node.py`, `edges/should_continue.py`, `tools/file_tool.py` | TC-01, TC-02 |
| M2 | Workspace + Context | `workspace/manager.py`, `context_assembler.py` | TC-05 |
| M3 | KB + exec + web | `web_tool.py`, `tool_registry.py`, skills | TC-03, 08~10 |
| M4 | memory + stop | `memory_tool.py` | TC-06, TC-07 |
| M5 | 全量验收 | — | TC-04 + 全部 |

当前迭代目标 = 第一个未完成的里程碑（脚本输出 `建议当前迭代目标: Mx`）。
